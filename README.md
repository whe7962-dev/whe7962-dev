### 🧭 关于我

我是 **何选（何宏） / Winnie**，一名在产品定义、体验设计与开发实践之间持续探索的 **AI 产品经理**。

我关注智能能力进入真实场景之后，人与系统的关系如何被重新组织：意图如何被理解，信息如何成为有效的上下文，决策如何被解释，以及用户在自动化过程中如何保有判断与控制。对我而言，这些问题共同决定了一款 AI 产品能否建立长期的信任。

我把产品设计理解为一种处理不确定性的方法：从具体情境中识别需求，通过原型把假设变成可以讨论的对象，再用交互反馈和实际结果修正判断。我希望把产品、设计与开发连成一个持续验证的过程，让每一次实现都能回答一个更清楚的问题。

这里记录我的产品实践与思考：关于技术如何成为体验，也关于效率、信任与人的感受如何在同一个系统里取得平衡。

> 把模糊的问题定义清楚，把复杂的能力交付得自然。

### 🔬 持续关注

- **上下文与产品判断**：关注信息的选择、组织与边界。怎样让系统在合适的时机获得必要信息，并在依据不足时保留不确定性？
- **人机协作与信任设计**：关注自动化中的解释、确认与接管。哪些决策适合交给 AI，哪些环节需要让用户看见、理解并保有选择？
- **从原型到价值验证**：关注体验、质量与成本之间的取舍。把“看起来可行”的方案放进具体任务中，检验它是否真正减少负担、改善结果。
