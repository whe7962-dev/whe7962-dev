### 关于我

我是 Winnie，一名关注产品设计与开发的 AI 产品经理。

我关心一个想法如何变成用户看得懂、愿意用的产品：从梳理需求，到设计界面，再到做出可以体验的版本。这里记录我的作品，也记录想法被做出来之后，值得继续改进的地方。

> 先做出一个能体验的版本，再把下一步想清楚。

### 正在打磨 · 宠拍档

**一个围绕科学养宠的品牌与网页交互原型。**

从健康咨询、营养照顾到日常陪伴，尝试把不同的养宠场景组织成容易理解的产品入口。

- **产品表达**：梳理五类功能入口，用具体场景说明产品能提供什么。
- **体验设计**：结合陪伴角色、生活故事与轻量动效，让页面更有亲近感。
- **开发实践**：使用 HTML / CSS / JavaScript 实现响应式页面，兼顾键盘操作与减少动态偏好。
